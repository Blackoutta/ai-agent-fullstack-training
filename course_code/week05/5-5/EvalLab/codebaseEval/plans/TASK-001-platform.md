落实 `../requirements/platform.md` R1-R9，遵循 `../design/architecture.md` 的共享契约。

## 工作包排序

| 工作包 | 角色 | 依赖 | 产物 |
|---|---|---|---|
| WP-001 数据与评测 | 后端 | 已确认设计 | backend/、tests/ |

## 验收标准

- [x] 任务与策略 CRUD、快照和导入验证。
- [x] 自动实验、隔离、取消、重启后的中断状态。
- [x] Trace、Judge、人工审查及未知处理。
- [x] 统计、失败聚类、同题比较和回归报告。
- [x] 后端测试、前端类型检查/构建、真实浏览器验证。实际覆盖与未完成浏览器项见 ../check/validation.md。

## 权限与风险

自动执行：平台源代码、单元测试、离线端到端验证。
需确认：联网实际模型调用（在 UI 选择真实运行）、部署到外网。
禁止：生产数据、自动审批、写入原始 Codebase、提交密钥。
未配置模型凭据时不降级冒充真实成绩；参考实现/离线样本与 live 分开统计。
