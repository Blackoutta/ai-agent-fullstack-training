## 4. 风险与阻塞项

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 跨实验/跨快照对比 | 结论不可比 | 配对条件硬约束：同实验、同任务快照、同 source_hash、同 trial |
| 缺失价格当免费 | 成本低估 | 已知成本与缺失成本分开计数，缺失价格保留 null |
| 聚类被当已确认根因 | 误导排障 | 命名"规则分组"，保留样本 ID 供回看证据 |
| 小样本通过被当稳定改善 | 误放行 | 报告注明小样本不证明统计稳定性；退化/未知一律 hold |
| 离线报告冒充真实成绩 | 门禁失效 | offline 报告永远 hold，离线标记常驻界面 |
