# 开发任务计划模板（TASK Template）

> PM 制定开发任务计划时使用。开发任务计划引用工作包文件路径，不得重新描述工作包内容。

```markdown
# TASK-XXX <开发任务名称>

## 1. 开发任务目标

<一句话说明本次开发任务要交付什么>

## 2. 开发任务周期

- 开始日期：YYYY-MM-DD
- 结束日期：YYYY-MM-DD
- 开发任务编号：XXX

## 3. 工作包排序

| 序号 | 工作包 | 负责角色 | 依赖 | 预估工时 |
|------|--------|---------|------|---------|
| 1 | WP-001-用户登录.md | 后端开发 | 无 | 2天 |
| 2 | WP-002-任务CRUD.md | 后端开发 | WP-001 | 3天 |

## 4. 风险与阻塞项

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 第三方API不稳定 | 可能延迟交付 | 提前准备Mock方案 |

## 5. 交付物清单

- [ ] 后端：$DELIVER_DIR/backend/
- [ ] 前端：$DELIVER_DIR/frontend/
- [ ] 移动端：$DELIVER_DIR/mobile/（如有）
- [ ] 运维：$DELIVER_DIR/ops/

## 6. 验收标准

- [ ] 所有工作包完成并通过审查
- [ ] 质量门禁全部通过
- [ ] 用户验收测试通过
```

## 填写说明

1. **开发任务目标**：简明扼要，一句话说清楚
2. **开发任务周期**：明确开始和结束日期
3. **工作包排序**：引用文件路径，说明依赖关系
4. **风险与阻塞项**：提前识别风险，准备应对措施
5. **交付物清单**：明确本次开发任务的交付物
6. **验收标准**：可勾选的验收项
