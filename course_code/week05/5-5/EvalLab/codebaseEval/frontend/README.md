# Codebase Eval 前端

Vue 3 + TypeScript strict + Vite 的中文评测工作台。仅请求同源 `/api`，无浏览器模拟数据、图片、外部字体或凭据存储。依赖精确锁定，`package-lock.json` 已生成。

## 启动

在此目录执行，使用 Node 22.12+ 或 Node 24：

```sh
npm ci
npm run dev
```

访问终端输出的本地 Vite 地址，默认 `http://127.0.0.1:5173`。开发代理默认指向 `http://127.0.0.1:8765`，这只是可配置的开发默认值，不是架构契约中的固定端口。不同 API 地址可通过环境变量配置：

```sh
EVAL_API_TARGET=http://127.0.0.1:你的端口 npm run dev
```

也可在此目录 `.env.local` 中配置 `EVAL_API_TARGET`。不要把模型 API Key 放进前端环境变量。API 未启动时显示明确连接错误，不填充模拟结果。

## 校验

```sh
npm run check
npm run test
npm run build
npm audit --registry=https://registry.npmjs.org
```

生产产物为 `dist/`。部署时由本地单体 HTTP 服务提供静态文件并处理同源 `/api`，或配置反向代理；前端没有改动后端。哈希导航不要求后端提供路由回退。

## 功能

- 概览：实际结果分布、成功率、已知费用、缺失费用/Token 计数、耗时、工具调用及失败率。
- Benchmark：创建、编辑、带确认删除、搜索、JSON 文件/文本导入、真实 API 导出。
- 策略：系统 Prompt、模型、API 基址、凭据变量名、Keyword/BM25、Top-K、可空价格。
- 实验：任务与策略多选、重复次数、超时与 Token 上限、预算计数、启动、5 秒轮询、确认取消。
- Trace：运行筛选、完整答案、任务/策略快照、模型工具时间轴、审计、召回证据。
- 评审：程序检查、独立 Judge、人工评审者/状态/理由、不可变历史。人工语义通过不能覆盖程序失败，最终结果仍使用后端判定。
- 失败聚类：显示后端分类与样本运行 ID，可跳转证据；不宣称分类就是已确认根因。
- 回归：同实验内选择基线与候选策略，展示服务端配对结果及门禁，JSON/Markdown 报告下载；变更比较条件清除旧报告。

离线警示常驻，运行/实验有模式标签，离线 Judge 禁用，离线回归门禁强制暂缓。没有运行/匹配数据时不推断成绩或改善。未记录费用显示“未知”，不当作零成本。

## 文件

- `src/types/index.ts`：设计契约 DTO 集中定义。
- `src/api/index.ts`：JSON 请求、错误、CRUD、评测、评审、报告与下载封装。
- `src/workspace.ts`：共享状态、去重刷新/提交、哈希导航、证据字段过滤和展示工具。
- `src/App.vue` / `src/styles.css`：深色侧栏、浅色主区、响应式壳层。
- `src/views/`：八个区域，每个页面不足 300 行。
- `src/components/`：运行列表/详情、证据时间轴、评审、弹窗、状态与空态，每个组件不足 300 行。
- `tests/`：Vitest + Vue Test Utils 的 API、工作流、证据/安全展示与整页导航测试。

## 安全与可访问性

使用 Vue 文本转义，禁止 `v-html`。证据 JSON 递归剔除思维链与明确敏感字段；服务端仍需负责原始字符串脱敏与授权。无任意路径执行入口，不自动批准工具。表单具备标签、原生约束与错误提示，弹窗支持 Escape/焦点循环/焦点恢复，导航和状态有文字，支持跳转主内容与减少动画。

## 验证边界

测试中的 fixture 仅用于单元/组件测试，不包含在生产数据流程。真实模型调用、后端鉴权/脱敏、源码快照隔离、实际 Judge 费用、服务端回归匹配和静态托管需在后端启动后联调。未运行浏览器截图/E2E 或全量覆盖率统计，不将组件测试冒充真实模型验收。
