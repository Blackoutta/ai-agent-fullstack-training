# Codebase Eval 平台需求

用户授权在 `codebase` 同级建立 `codebaseEval`，参考 `eval_lab` 与课程口播稿。
采用用户确认的本地单体：Python API + SQLite + Vue 3/TypeScript。
本地 `skills/software-delivery-*` 指导需求、设计、实现、测试，Java 示例不作为技术栈要求。

## 功能与验收

- R1 Benchmark：任务新增、编辑、删除、JSON 导入导出；运行保留任务版本快照。
- R2 自动评测：任务 × 策略 × 重复次数；独立源码副本、新会话、预算、取消、进度与失败记录。
- R3 策略对比：系统 Prompt、模型、基址、价格、RAG 模式/top-k；配置快照不可被后续编辑改变。
- R4 Trace：实际模型消息、受治理工具、审计、召回证据、时间轴；脱敏、不展示思维链。
- R5 评分：程序检查、证据约束 LLM Judge、带评审者和理由的人工评分历史；运行错误不能被人工改成成功。
- R6 统计：成功/失败/未知、Token、已知成本与缺失成本、耗时、工具次数及失败率。
- R7 失败聚类：按可追溯失败类别分组，保留样本 ID，不冒充已确认根因。
- R8 前后比较：只匹配同任务快照/源码/重复序号，逐题改善与退化；无匹配数据不给结论。
- R9 回归报告：同条件策略对比，必须完成全部配对，核心任务失败/未知暂缓采用；JSON/Markdown 导出。

## 边界

仅运行本机可信 Codebase 源码快照；不执行用户上传的任意命令，不批准写入、不访问生产。
默认 Agent 只读，只使用 Runtime 仓库读取工具。独立目录不是 OS 沙箱。
模型凭据来自本机环境变量，不保存到数据库或浏览器。
离线验证只检查平台链路，不作为真实模型成绩。RAG 为本机文档检索，不声称向量检索。
不修改 `eval_lab` 或口播稿，不自动提交或推送。
