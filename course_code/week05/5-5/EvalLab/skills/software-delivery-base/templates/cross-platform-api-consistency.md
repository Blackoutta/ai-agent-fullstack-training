## 不一致类型定义

| 类型 | 说明 |
|------|------|
| 路径不一致 | 前端/移动端调用的URL路径与后端定义不同 |
| 方法不一致 | HTTP方法（GET/POST等）不一致 |
| 参数不一致 | 请求参数名/类型/必填性不一致 |
| 响应格式不一致 | 返回字段名/类型/结构不一致 |
| 错误码不一致 | 错误码定义或处理方式不一致 |

## 检查方法

### 后端→前端对齐
1. 提取后端所有 @RequestMapping/@GetMapping/@PostMapping 等注解
2. 提取前端 src/api/ 目录下所有API调用
3. 逐个比对路径、方法、参数

### 后端→移动端对齐
1. 提取后端所有API端点
2. 提取移动端网络请求层所有API调用
3. 逐个比对路径、方法、参数

### DTO对齐
1. 后端响应DTO字段 vs 前端TypeScript类型定义
2. 后端请求参数 vs 前端/移动端请求参数类型
3. 字段名命名风格一致性（camelCase/snake_case）
