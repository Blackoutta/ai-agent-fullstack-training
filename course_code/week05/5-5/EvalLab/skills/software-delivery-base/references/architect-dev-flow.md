## 沟通和确认机制

- **架构师与研发人员直接沟通**：架构师需向研发人员介绍框架结构和使用方式，研发人员确认理解后方可开始编码
- **框架调整沟通流程**：研发人员如需调整框架结构，需通过 `question` 工具向架构师提出调整请求
- **问题升级机制**：研发人员遇到框架相关问题时，首先通过 `question` 工具向架构师提问；如架构师无法解决，可升级至 PM 协调解决
- **沟通记录**：重要沟通内容需记录在 `$CHECK_DIR/` 目录下，便于追溯和审查
