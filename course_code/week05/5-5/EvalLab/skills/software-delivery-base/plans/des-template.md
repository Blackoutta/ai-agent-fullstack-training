# 开发任务设计文档模板（DES Template）

> 架构师生成开发任务设计文档时使用。开发任务设计文档引用已有设计文档出处，不重复抄写。
> **注意**：模板中的设计文档编号（如 `04-api-design.md`）为示例值，实际编号以 `$DESIGN_DIR` 目录下的文件为准。

```markdown
# DES-XXX <开发任务名称>

## 1. 概要

<一句话说明本次开发任务的技术方案>

## 2. 技术栈

| 层 | 技术选型 | 说明 |
|----|---------|------|
| 架构类型 | 单体/微服务 | 按设计文档 |
| 后端 | Java + Spring Boot + MyBatis | 按设计文档 |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus | 按设计文档 |
| 数据库 | MySQL 8.0 | 按设计文档 |

## 3. 接口设计（api）

| 接口 | 方法 | 路径 | 说明 | 详见 |
|------|------|------|------|------|
| 用户登录 | POST | /api/v1/auth/login | 用户登录 | $DESIGN_DIR/04-api-design.md §3 |

## 4. 数据库设计（db）

| 表名 | 变更类型 | 说明 | 详见 |
|------|---------|------|------|
| users | 新增 | 用户表 | $DESIGN_DIR/03-database-design.md §2 |

## 5. 前端设计（frontend）

| 页面/组件 | 路径 | 说明 | 详见 |
|----------|------|------|------|
| 登录页 | views/Login.vue | 用户登录 | $DESIGN_DIR/05-frontend-design.md §4 |

## 6. 移动端设计（mobile，若有）

| 页面/组件 | 路径 | 说明 | 详见 |
|----------|------|------|------|
| ___ | ___ | ___ | $DESIGN_DIR/06-mobile-design.md §X |

> 若本次开发任务不涉及移动端，标注"N/A - 本次开发任务无移动端功能"。

## 7. 业务流程

<时序图/流程图，说明关键业务流程>

## 8. 关键算法/规则

<核心计算逻辑、状态机、边界条件>

## 9. 运维/部署设计（ops）

| 产物 | 路径 | 说明 | 详见 |
|------|------|------|------|
| Dockerfile | ops/Dockerfile | 容器化配置 | $DESIGN_DIR/07-deployment-design.md §X |

> 若本次开发任务不涉及运维变更，标注"N/A - 本次开发任务无运维变更"。

## 10. 约束与边界

<性能指标、并发控制、幂等、限流策略>
```

## 填写说明

1. **概要**：简明扼要，一句话说清楚技术方案
2. **技术栈**：按设计文档填写，不要随意更改
3. **接口设计**：引用已有设计文档出处，不重复抄写
4. **数据库设计**：说明本次开发任务的表结构变更
5. **前端设计**：说明本次开发任务的页面/组件
6. **移动端设计**：说明本次开发任务的移动端页面/组件（若无则标注 N/A）
7. **业务流程**：用时序图或流程图说明关键业务流程
8. **关键算法/规则**：核心计算逻辑、状态机、边界条件
9. **运维/部署设计**：CI/CD、容器化、监控配置（若无变更则标注 N/A）
10. **约束与边界**：性能指标、并发控制、幂等、限流策略
