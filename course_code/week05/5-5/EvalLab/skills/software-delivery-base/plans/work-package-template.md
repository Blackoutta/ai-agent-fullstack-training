# 工作包模板（WP Template）

> PM 拆分需求时使用。按粒度递进：小任务只写目标+约束+验收；中等任务补接口/表结构；大需求拆子包。
> 三色权限标签见 templates/spec-coding.md。

```markdown
# WP-XXX <工作包名称>

## 1. 目标
<一句话说明要交付什么>

## 2. 范围
- 包含：<列表>
- 不包含：<列表，明确边界>

## 3. 关键业务规则
- <规则1，条件→预期行为，可测试>
- <规则2>

## 4. 接口契约（中等/大任务必填，OpenAPI 风格）
| 方法 | 路径 | 说明 | 关键入参/出参 | 错误码 |
|------|------|------|---------------|--------|
| POST | /api/v1/... | ... | ... | ... |

## 5. 数据模型（中等/大任务必填）
| 表 | 关键字段 | 约束/索引 |
|----|----------|-----------|
| ... | ... | ... |

## 6. 验收标准（可勾选）
- [ ] <标准1>
- [ ] <标准2>

## 7. 三色权限标签
- ✅ Always：<AI 可自动执行>
- ⚠️ Ask First：<需用户确认，如改索引/改公共API>
- 🚫 Never：<禁止，如删预置角色/直连生产库>

## 8. 依赖
- 依赖 WP：<前置工作包>
- 被依赖：<后续工作包>

## 9. 负责角色
<后端开发/前端开发/移动端开发/数据库工程师/测试/运维>
```
