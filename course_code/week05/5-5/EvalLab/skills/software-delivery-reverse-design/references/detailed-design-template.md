- 如果不能匹配，这对贷款投向分组进行遍历，判断为\*号结尾的贷款投向，截取\*号和贷款投向进行模糊匹配，存在则将结果赋值到returnMap中的codeList中；

- 如果codeList中的对象含有备注REMARK信息，则拼接"名称"列+"REMARK"列，若多个提示使用符号分开赋值returnMap中的message字段中并返回数据；

- 如果不存在映射关系则置returnMap的flag赋值为产业贷款标识为否，设置reteurnMap的disabled为不可修改，设置reteurnMap的codeList为空数组后返回数据。
