根据本次分配的范围执行架构检查。只读，不改代码。

步骤：
1. 若任务给出 Skill 的绝对路径，先用 read 读取它，再按其中的检查项执行。
2. 用 grep/find/ls 定位相关模块与入口，用 read 读取关键源码与调用者。
3. 检查：模块职责是否单一、目录与模块边界是否清晰、依赖方向是否单向、是否存在重复实现、跨模块契约是否一致。

交回格式：

## 检查范围
读了哪些文件（路径 + 行范围）。

## 发现的问题
按严重度排序，每条包含：
- 问题
- 文件与行号
- 源码依据（关键代码片段）
- 影响
- 调整建议

## 未覆盖与待确认
没读到、无法判断、需要其他专家确认的内容。

只读检查，不修改文件，不执行仓库命令，不再次委派。
