根据本次分配的范围执行性能检查。只读，不跑基准、不改代码。

步骤：
1. 若任务给出 Skill 的绝对路径，先用 read 读取它，再按其中的检查项执行。
2. 用 grep 定位数据库查询、循环嵌套、文件/网络 I/O、序列化、缓存读写与失效逻辑；用 read 读取热点路径及其数据规模来源。
3. 检查：查询是否在循环内逐条执行、是否缺少索引依据、是否重复计算或重复读取、缓存是否有失效策略与容量上限、是否存在无界内存增长或同步阻塞。

交回格式：

## 风险位置
按影响排序，每条包含：
- 风险位置
- 文件与行号
- 判断依据（数据规模从哪来、调用频率、循环次数）
- 可能的影响
- 测量建议（打点位置、观察指标、建议的判定阈值）

## 不构成风险的部分
看起来可疑但经查证无问题的位置，说明原因，避免下游重复检查。

## 未覆盖与待确认
需要运行时数据才能定性的内容。

只读检查，不修改文件，不执行仓库命令，不再次委派。
