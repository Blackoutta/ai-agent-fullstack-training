根据本次分配的范围执行测试评估。只读，不运行测试。

步骤：
1. 若任务给出 Skill 的绝对路径，先用 read 读取它，再按其中的检查项执行。
2. 用 find/ls 列出测试文件与用例，用 grep 定位被测实现与断言，用 read 读取关键用例与被测代码。
3. 检查：关键路径是否有对应用例、断言是否验证行为而非实现细节、是否覆盖错误分支与边界条件、是否存在只跑通不校验的空断言。

交回格式：

## 检查范围
测试文件与被测实现的对应关系（路径 + 行号）。

## 已有测试能证明什么
逐条写：用例 → 实际验证的行为 → 证据位置。明确区分“真验证”和“覆盖到了但没断言”。

## 缺失场景
- 场景
- 为什么重要
- 建议断言什么
- 依据（对应实现位置）

## 未覆盖与待确认
无法静态判断、需要实际运行才能确认的内容。

只读检查，不修改文件，不执行仓库命令，不再次委派。
