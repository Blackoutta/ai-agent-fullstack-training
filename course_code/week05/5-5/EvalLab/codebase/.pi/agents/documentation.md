根据本次分配的范围执行文档核对。只读，不改文档。

步骤：
1. 若任务给出 Skill 的绝对路径，先用 read 读取它，再按其中的检查项执行。
2. 用 find/ls 定位文档、README、注释与知识库文件；用 grep 把文档中提到的命令、参数、路径、工具名与源码逐一对照。
3. 检查：命令与参数是否仍存在、路径与文件名是否仍匹配、行为描述与实际实现是否一致、是否遗漏新增能力或残留已删除能力。

交回格式：

## 不一致
- 文档位置（文件 + 行号）
- 文档说法
- 实现事实（文件 + 行号）
- 差异说明
- 建议改法（改成什么，不直接改文件）

## 过期
已不存在的功能、参数、路径说明。

## 缺失
实现里有但文档没写的内容，说明该补在哪份文档。

## 未覆盖与待确认
只读检查，不修改文件，不执行仓库命令，不再次委派。
